# Integration——一个减轻综测整理负担的辅助系统

> 目前针对计算机学院进行一个实验性产品产出，后续会针对不同的学院进行优化
## 1️⃣主要流程图
> 因为每年的要求不同，上传的综测要求会有差错，针对这两年的综测提交，我归纳成如下的过程
> 
**注意**：还存在个问题，PDF文件关于智育的活动除了参加学科比赛，其他无关的都不算，这个后续需要解决（人工）
```mermaid
flowchart TD
A["用户进入系统"] --> B["选择所在学院、综测学年"]
B --> C["上传学院综测要求"]
C --> C1["综合测评表、加分明细表"]
C --> C2["重要学术期刊目录、竞赛项目目录"]
C --> C3["学院综测评分细则、材料压缩包分布要求"]
C1 --> D["读取已发布的学院规则"]
C2 --> D
C3 --> D
D --> E["用户上传上学年绩点及各项综测 PDF"]
E --> F["文件解析、材料清单识别"]
F --> G["按红头文件、活动类别和规则进行初步分类"]
G --> H["生成待整理材料清单"]
H --> I["用户核对、补充或调整分类"]
I --> J["截图、裁剪、拼图、重命名"]
J --> K["生成材料预览及待核算数据"]
K --> L["代码规则引擎计算综测分数"]
L --> M["生成计算结果概览"]
M --> N["用户检查结果"]
N --> O{"是否存在问题？"}
O -- 是 --> P["AI 辅助修改或用户手动调整"]
P --> K
O -- 否 --> Q["用户最终确认"]
Q --> R["按学院要求生成目录结构"]
R --> S["导出 Excel、整理证明材料"]
S --> T["按规则重命名并打包"]
T --> U["用户下载最终压缩包"]

```
