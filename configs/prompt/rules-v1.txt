你在把一份高校综合测评加分细则的表格页转成机器可读的规则。只抽事实，不推断、不补全。

输出一个 JSON 对象，不要代码块、不要解释：
{
  "dimension": "moral|intellect|physique|aesthetic|labour|null",
  "section": "本页所属章节标题原文，如「二、智育测评」；判断不出就 null",
  "has_table": true,
  "groups": [
    {
      "name": "组名，取自本页小标题，如「参与专业技能竞赛获奖」",
      "kind": "bonus|penalty",
      "evidence": "该组加分说明的原文首句",
      "note": "表格备注 / 补充说明 / 脚注原文，没有则 null",
      "items": [
        {
          "title": "条目名，形如「国家级一等奖」",
          "level": "国家级|省级|市级|校级|院级|不确定",
          "rank": "等次原文，如 一等奖 / 二等奖 / 干事 / 一学年",
          "score": 20
        }
      ]
    }
  ],
  "problems": ["读不清、拿不准、或结构对不齐的地方，如实写在这里"]
}

铁律：
1. 分值必须来自表格，逐格对齐。**不许按规律外推，不许自己补空格**。
   表里留空的格子就不输出那条 item。
2. 一个单元格里有多行文字的，按行拆成多条 item。
3. 表格的「级别」通常在左侧竖列、「等次」在顶部横排，不要搞反。
   斜线表头（一格分两半）往往就是「级别 ↓ / 等次 →」，斜线下方那半边才是行标题。
4. 纵向合并的单元格（一个分值跨多行组织名）表示**这些组织共用同一分值**：
   只输出一条 item，把组织名写进 note，例如
   "note": "适用于：团委、学生会/学生社联、党建中心…"
5. 备注、补充说明、脚注必须原样保留在 note 里，不能丢——那里常写着"不累加""按最高计"这类决定性规则。
6. 本页如果没有评分表格（纯文字条款、目录、评选条件说明），has_table 填 false，
   groups 给空数组。不要为了凑数把条款编成规则。
7. 拿不准的行宁可不输出，写进 problems。**留空比写错有价值**——写错会直接算错分。
8. 如果同一条规则在本页与前页重复（续页表），只输出本页新增的部分，不要重复前页已给的条目。
